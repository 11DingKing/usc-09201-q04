# 林权融资占用监测领域约定

项目面向集体林权改革与林下产业协作场景。业务记录需要区分来源、发生时间与当前
有效版本；涉及个人、机构或敏感地点的信息只向职责范围内的角色开放；所有对外结果
都必须能够追溯到采用的数据版本。

## 领域对象

- **权证（Certificate）**：经营权证，含权证编号、权利人与有序地块列表。
- **地块（Plot）**：林权最小占用单元，带面积（亩）与位置；同一时刻至多附着一笔授信。
- **估值版本（Valuation）**：仅追加，含评估时点、总额与分地块估值。新版本不覆盖
  旧版本，所有授信余量按“当前版本”实时重算，旧版本保留更正轨迹。
- **授信（Credit）**：金融机构冻结的额度，附着一组有序地块，状态机为
  `frozen → revoking → revoked`；地块全部清偿释放后亦可自动 `closed`。
- **提款（Drawdown）/ 偿还（Repayment）**：分期发生，余额由事件折叠得出。
- **释放（Release）**：部分地块解除占用，必须遵循附着先后次序（FIFO）。

## 关键约定

1. **可融资上限** = 地块当前估值 × 抵质押率（0.7）。授信可提款上限取冻结额度与
   附着地块可融资上限的较小值。
2. **占用互斥**：地块级互斥防止同一权利重复用于不同授信；并发请求由事件日志的
   全序与乐观锁裁定，冲突方收到结构化冲突响应。
3. **确定次序**：撤销请求先阻断新提款，清偿后才能确认解除；释放按 FIFO 前缀进行。
4. **幂等回执**：机构命令可携带幂等键，乱序重投返回首次结果。
5. **数据隔离**：机构只可见本机构授信明细；他机构占用仅以占位信息呈现；监管可见全量。
6. **可追溯**：事件不可变并带前向哈希链，监管可只读事件独立重放、验篡改。
